# SOL-014 · Unchecked integer arithmetic

`+ - *` on ints without `checked_*` → release builds wrap silently, and the wrap IS the bug. Fix: `a.checked_add(b).ok_or(Overflow)?`.

**Enforcement — machine-checkable.** A deterministic pattern flags this automatically in the [CLI](../../cli), the [GitHub Action](../../action.yml), the [Semgrep ruleset](../../semgrep), the [VS Code extension](../../extensions/vscode), and the [MCP server](../../mcp).

## Real exploits in this class

No publicly catalogued exploit in the [Hacks Database](../../hacks/README.md) maps to this class yet. The rule is drawn from documented Solana audit patterns, not a specific in-the-wild loss.
