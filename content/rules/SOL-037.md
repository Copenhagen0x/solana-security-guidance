# SOL-037 · Arbitrary CPI target

A CPI whose callee program id comes from an account or instruction data that's never checked against the expected program → attacker redirects the call to a malicious program. (SOL-009 checks the CALLER's authority; this checks the CALLEE's identity.) Fix: pin the callee — a typed `Program<'info, T>`, or assert the program id equals the expected constant — AND validate the accounts (and any PDA-signer seeds/amounts) passed into the CPI; pinning the program alone leaves account substitution / confused-deputy open (see SOL-027).

**Enforcement — review-only.** A judgment-call class with no deterministic pattern: it lives in the standard's review checklist and in your AI agent's [rules file](../../integrations), so the model reviews for it.

**Value tier — HIGH.** HIGH — high-value; surfaced even at a strict submission floor

**Baseline severity — high.** A starting point, not a verdict: calibrate by preconditions × access level (take the lower) per [SEVERITY.md](../../SEVERITY.md).

**Reachability anchor.** To confirm this is exploitable (not merely present), cite the invoke/invoke_signed call site whose target program id is not pinned to an expected program.

**Do NOT flag when** — cite the number when suppressing a finding:

1. the callee program is pinned (a typed Anchor `Program<'info, T>`, or its key asserted == the expected hardcoded/config-stored program id) AND the accounts passed into the CPI are validated/pinned — for an `invoke_signed` that carries this program's PDA authority, a pinned program with attacker-substituted accounts is still a confused-deputy drain (cite SOL-027 for the account validation)
2. the program id AND the account metas are all hardcoded constants / program-derived in the CPI call itself (not read from caller-supplied accounts or instruction data), so neither the callee nor its accounts can be redirected
3. this is SOL-009's concern (missing CALLER authority) rather than an unpinned CALLEE — cite SOL-009 instead; SOL-037 is specifically the callee-identity gap
