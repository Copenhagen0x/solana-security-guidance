# SOL-003 · Wrapper re-implements engine

Wrapper handler redoes engine logic (close/settle/accrue), drifts, skips side-effects. Fix: delegate to the engine; the wrapper only marshals accounts.

**Enforcement — review-only.** A judgment-call class with no deterministic pattern: it lives in the standard's review checklist and in your AI agent's [rules file](../../integrations), so the model reviews for it.

## Real exploits in this class

No publicly catalogued exploit in the [Hacks Database](../../hacks/README.md) maps to this class yet. The rule is drawn from documented Solana audit patterns, not a specific in-the-wild loss.
