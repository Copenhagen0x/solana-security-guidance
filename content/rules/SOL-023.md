# SOL-023 · Fee/penalty rounds toward the user

Fee/penalty uses integer `/` (rounds down) → user underpays, dust → 0 (evasion + leakage). Fix: `u64::div_ceil` what the user **owes**; round against the less-trusted party (fee UP, payout DOWN). *(v16 audit F3, Low)*

**Enforcement — review-only.** A judgment-call class with no deterministic pattern: it lives in the standard's review checklist and in your AI agent's [rules file](../../integrations), so the model reviews for it.

**Value tier — LOW.** LOW — hygiene / defense-in-depth / operational (filtered out by `--min-tier high`)

**Reachability anchor.** To confirm this is exploitable (not merely present), cite the fee/penalty integer division that rounds in the user's favor.
